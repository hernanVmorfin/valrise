# VALRISE website logo pack

Based on the selected Sculpted Partnership design with the clarified L, black VAL, and blue RISE.

## Start here

- Website header: `svg/valrise-header-color.svg`
- Full logo with tagline: `svg/valrise-full-color.svg`
- Wordmark without monogram: `svg/valrise-wordmark-color.svg`
- Standalone monogram: `svg/valrise-monogram-color.svg`
- Browser tab icon: `icons/favicon.ico`
- Apple touch icon: `icons/apple-touch-icon.png`

SVG is preferred on the website. All lettering is outlined as vector paths, so no fonts or external resources are required. PNG files have transparent backgrounds and are exported from the SVG artwork.

## Color versions

- `color`: black with RISE in blue #3DA2EF. The standalone monogram remains black.
- `black`: entirely black.
- `reverse`: white with RISE in blue #3DA2EF, for dark backgrounds. The standalone monogram is white.

## PNG widths

- Full signature: 2400 and 1200 pixels.
- Header and wordmark: 1600 and 800 pixels.
- Monogram: 512 and 256 pixels.
- Square transparent icons: 32, 48, 180, 192, and 512 pixels.

The 180-pixel Apple touch icon and ICO use white backgrounds for visibility.

## Website use

Upload the desired SVG and preserve its aspect ratio. Use the header version when the full tagline would be too small. Use the monogram for compact mobile navigation and icons. Give logo images the alternative text "Valrise Consulting".

```html
<img src="/assets/valrise-header-color.svg" alt="Valrise Consulting" width="280" style="height:auto;max-width:100%">
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
```

## Artwork note

These are real vector traces of the selected generated artwork, with flat brand colors; they are not raster images embedded in SVG files. They preserve the selected appearance rather than constituting a freshly drawn typographic master. Light and dark previews are included for review and are not transparent production files.
