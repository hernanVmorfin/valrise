# Launch checklist

## Assets and approvals

- [ ] Approved Valeria portrait, crops, credit, and alternative text replace the development frame.
- [ ] Approved long and short biography; birthplace, immigration history, prior business, and any sale language cleared individually.
- [ ] Three service categories and possible engagement formats approved.
- [ ] Four proposed speaking topics and takeaways approved.
- [ ] Real inquiry recipient email configured and monitored.
- [ ] Scheduling URL supplied only if direct scheduling is desired.
- [ ] Social links and contact details supplied and verified.
- [ ] Privacy and Terms reviewed by qualified counsel and published intentionally.
- [ ] No unsupported client, result, credential, award, event, media, location, or testimonial claim appears.

## Functional acceptance

- [ ] Theme and plugin install from the release ZIP files.
- [ ] `wp valrise seed` creates the intended pages without replacing unrelated content.
- [ ] Header, footer, navigation, content, services, speaking topics, and imagery remain editable in WordPress.
- [ ] Desktop, tablet, and mobile navigation work without a development server.
- [ ] Keyboard focus remains visible; navigation, disclosures, form fields, and error recovery work without a mouse.
- [ ] Consultation and speaking validation reject incomplete requests.
- [ ] A forced mail failure shows an error; success appears only after a successful mail handoff.
- [ ] No browser console error occurs on representative public pages.
- [ ] Empty Insights does not display on Home; published articles display in the archive and related content.

## Search, privacy, and performance

- [ ] Production URL, site title, and tagline confirmed in WordPress settings.
- [ ] Staging noindex removed only after canonical-domain confirmation.
- [ ] Core XML sitemap loads and contains only intended public URLs.
- [ ] One metadata owner is active; no duplicate canonical, Open Graph, or schema output.
- [ ] Organization, Person, Article, and breadcrumb schema contains verified information only.
- [ ] Images have intrinsic dimensions, appropriate formats, meaningful alternative text, and below-the-fold lazy loading.
- [ ] Mobile Lighthouse and WebPageTest runs recorded with device, connection, page, cache state, and remaining issues; no guaranteed score is claimed.
- [ ] Backups and rollback archives are current and recoverable.
